# Carpeta CSS organizada

Usa `assets/css/app.css` como unico archivo enlazado desde el HTML/PHP.

- `base/global.css`: reset, fondo global, contenedores, titulos, animaciones.
- `layout/header.css`: barra superior y navegacion.
- `layout/footer.css`: pie de pagina.
- `componentes/ui.css`: tarjetas, botones y utilidades reutilizables.
- `componentes/styles.css`: reservado para compatibilidad; no pegar paginas completas aqui.
- `paginas/index.css`: hero, menu publico y secciones del inicio.
- `paginas/contacto.css`: formulario de contacto y tabs.
- `paginas/admin.css`: dashboard principal del administrador.
- `paginas/crear.css`: formularios de crear/editar plato.
- `paginas/menu.css`: tabla/listado de platos.
- `paginas/login.css`: login del administrador.
